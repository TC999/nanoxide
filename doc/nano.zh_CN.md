# GNU nano 文本编辑器

**版本 9.2**  
**版次 0.9**  
**2026 年 7 月**

---

## 引言

GNU `nano` 是一款小巧友好的文本编辑器。除了基本的文本编辑功能，`nano` 还提供撤销/重做、语法着色、交互式搜索替换、自动缩进、行号、单词补全、文件锁定、备份文件以及国际化支持等特性。

`nano` 最初的目标是成为 Pico 的完全 bug 级兼容仿真。但目前的目标是在合理范围内尽可能兼容，同时提供 Pico 功能的超集。有关 `nano` 与 Pico 差异的更多详情，请参阅 [Pico compatibility](#pico-compatibility)。

自 4.0 版本起，`nano` 默认不再对超长行进行硬换行。同时默认使用逐行滚动，并默认将标题栏下方的一行包含在编辑区域中。如果你想恢复旧的 Pico 行为，可以使用以下选项：`--breaklonglines`、`--jumpyscrolling` 和 `--emptyline`（或 `-bje`）。

自 8.0 版本起，`^F` 开始正向搜索，`^B` 开始反向搜索，`M-F` 正向搜索下一个匹配项，`M-B` 反向搜索下一个匹配项。如果你希望这些按键执行 8.0 版本之前的操作，请参阅示例 nanorc 文件中的重新绑定。

自 9.0 版本起，所有行会一起水平滚动（当光标接近边缘时），并且仅滚动所需的量，而不是仅将当前行滚动较大步长。如果你更喜欢旧行为，可以在命令行中使用 `--solo`，或在 nanorc 文件中使用 `set solosidescroll`。

同样自 9.0 版本起，按键 `M-<` 和 `M->` 已重新分配给 `scrollleft` 和 `scrollright` 功能。如果你希望这些按键执行 9.0 版本之前的操作，请参阅示例 nanorc 文件中的重新绑定。

请通过 <https://savannah.gnu.org/bugs/?group=nano> 报告 bug。

有关使用 nano 的问题，可以发送至 <mailto:help-nano@gnu.org>。

背景信息请参阅 <https://nano-editor.org/>。

## 调用

调用 `nano` 的常用方式是：

```
nano [FILE]
```

但也可以指定一个或多个选项（参见 [命令行选项](#command-line-options)），并连续编辑多个文件。

可以通过在文件名前添加带加号的行号，将光标置于文件的特定行；甚至可以通过添加逗号和列号，将光标置于特定列。负数从文件或行的末尾开始计数。

可以通过在文件名前指定 `+/` 或 `+?` 后面的字符串，将光标置于该字符串的第一次或最后一次出现处。通过在加号后插入 `c` 和/或 `r`，可以使字符串区分大小写和/或被解释为正则表达式。这些搜索模式可以通过使用这些字母的大写变体（`C` 和/或 `R`）显式禁用。当字符串包含空格时，需要用引号括起来。因此，更完整的命令语法为：

```
nano [OPTION]... [[+LINE[,COLUMN]|+[crCR]{/|?}STRING] FILE]...
```

不过，通常情况下，你会在 `nanorc` 文件中设置首选选项（参见 [Nanorc 文件](#nanorc-files)）。并且当你使用 `set positionlog`（使 `nano` 在关闭文件时记住光标位置）时，很少需要指定行号。

特殊情况：当给出短划线 `-` 而不是文件名时，`nano` 将从标准输入读取数据。这意味着你可以将命令的输出直接导入缓冲区，然后进行编辑。

## 编辑器基础

### 屏幕布局

`nano` 的默认屏幕由四个区域组成。从上到下依次是：标题栏、编辑窗口、状态栏和两行帮助行。

标题栏由三部分组成：左侧、中间和右侧。左侧部分显示正在使用的 `nano` 版本。中间部分显示当前文件名，如果文件尚未命名则显示“New Buffer”。右侧部分在文件自上次保存或打开以来已被修改时显示“Modified”。

状态栏是屏幕底部向上数的第三行。它显示重要和信息性消息。使用编辑器时出现的任何错误消息都会显示在状态栏上。向用户提出的任何问题都会在状态栏上提出，任何用户输入（搜索字符串、文件名等）也都在状态栏上输入。

屏幕底部的两行帮助行显示编辑器的一些最基本功能。

### 输入文本

`nano` 是一个“无模式”编辑器。这意味着除了 Control 和 Meta 序列之外，所有按键都会将文本输入到正在编辑的文件中。

键盘上不存在的字符可以通过两种方式输入：

- 对于单字节代码的字符，按 Esc 键两次，然后输入三位十进制数字（从 `000` 到 `255`），会使 `nano` 表现得就像你输入了该值的按键。
- 对于任何可能的字符，按 `M-V`（Alt+V），然后输入一系列十六进制数字（最多六位，或用 `Enter` 或 `Space` 结束）会将相应的 Unicode 字符输入到缓冲区。

例如，输入 `Esc Esc 2 3 4` 会输入字符“ê”——在写法国派对时很有用。输入 `M-V 0 0 2 2 c 4` 会输入符号“⋄”，一个小菱形。

输入 `M-V` 后跟任何非十六进制数字的内容，会将该按键逐字输入到缓冲区，允许用户插入字面控制代码（`^J` 除外）或转义序列。

### 命令

命令通过 Control 键（Ctrl，显示为 `^`）或 Meta 键（Alt 或 Cmd，显示为 `M-`）给出。

- 控制键序列的输入方法是：按住 Ctrl 键并按下所需按键。
- Meta 键序列的输入方法是：按住 Meta 键（通常是 Alt 键）并按下所需按键。

如果出于某种原因，在你的系统上 Ctrl 或 Alt 组合键不起作用，你可以使用 Esc 键来生成它们。控制键序列通过按 Esc 键两次然后按下所需按键来生成，Meta 键序列通过按 Esc 键一次然后按下所需按键来生成。

### 剪切缓冲区

可以使用 `^K` 一次从文件中剪切整行文本。被剪切的行存储在剪切缓冲区中。连续按 `^K` 会将每一行剪切的内容添加到该缓冲区，但在任何其他按键之后按 `^K` 会覆盖整个剪切缓冲区。

剪切缓冲区的内容可以使用 `^U` 粘贴到当前光标位置。

可以使用 `M-6` 将一行文本复制到剪切缓冲区（而不剪切它）。

### 标记

可以通过先用 `^6` 或 `M-A` “设置标记”，然后将光标移动到要选择部分的另一端来选择文本。选中的文本部分会高亮显示。现在可以通过一次 `^K` 或 `M-6` 整体剪切或复制此选择。或者，该选择可用于限定搜索替换（`^\`）或拼写检查会话（`^T^T`）的范围。

在某些终端上，也可以在使用光标键的同时按住 `Shift` 来选择文本。同时按住 `Ctrl` 或 `Alt` 键会增加步长。这样的选择会在任何未按住 `Shift` 的光标移动时取消。

剪切或复制选中文本会自动关闭标记。如果需要，可以通过再次按 `^6` 或 `M-A` 手动关闭。

### 搜索和替换

使用搜索命令（`^F` 或 `^W`），你可以在当前缓冲区中搜索任何字符串的出现。默认搜索模式是正向、不区分大小写且针对字面字符串。但你可以通过切换 `M-B` 向后搜索，使用 `M-C` 区分大小写搜索，以及使用 `M-R` 在搜索字符串中解释正则表达式。

使用替换命令（`M-R` 或 `^\`），你可以将给定的字符串（或正则表达式）替换为另一个字符串。当正则表达式包含括号内的片段时，替换字符串可以通过 `\1` 到 `\9` 引用这些片段。

对于搜索字符串的每次出现，都会询问你是否替换它。你可以选择 Yes（替换它）、No（跳过此一次）、All（替换所有剩余的出现，不再询问）或 Cancel（停止替换，但已经完成的替换不会被撤销）。

如果在替换会话开始前标记了一个区域，则仅替换标记区域内的搜索字符串出现。

正则表达式始终只覆盖一行——不能跨越多行。并且搜索字符串和替换字符串都不能包含换行符（LF）。

### 使用鼠标

当鼠标支持已配置并启用时，单击鼠标可将光标置于指示的位置。在同一位置再次单击可切换标记。单击两行帮助行会执行所选快捷键。要能够使用左键选择文本，或使用中键粘贴文本，请在这些操作期间按住 Shift 键。

鼠标在 X Window 系统中有效，并且在运行 gpm 的控制台上也有效。

### 锚点

使用 `M-Ins`，你可以在当前行放置一个锚点（一种书签）。使用 `M-PgUp` 和 `M-PgDn`，你可以在向后/向前方向跳转到锚点。这种跳转在顶部和底部会环绕。

当某个操作删除了带有锚点的行时，光标所在的新行会继承该锚点。但在对整个缓冲区执行操作（如格式化、通过命令管道传输或进行外部拼写检查）后，之前存在的任何锚点都会消失。

当 `--positionlog` 或 `set positionlog` 处于活动状态时，锚点会在文件关闭时保存，并在文件重新打开时恢复。

如果启用了行号，锚点会在左边距中可视化显示，并且在迷你栏中始终（在右侧）可视化显示。

### 宏

要录制一系列需要多次执行的按键，请使用 `M-:` 开始录制，仔细输入一系列按键，然后再次使用 `M-:` 停止录制。录制的结果称为键盘宏。你可以使用 `M-;` 根据需要多次重放此宏。

当你误按了 `M-:`（recordmacro）时，请立即再次按 `M-:` 以取消录制。这样，已有的宏就不会被覆盖。

注意：键盘宏的录制和重放仅在终端模拟器上正常工作，在 Linux 控制台（VT）上不能正常工作，因为后者默认不区分已修改和未修改的光标键。

### 退出状态

当 `nano` 正常完成时，退出状态为 `0`；当给出了无效选项或选项参数时，退出状态为 `1`；当最后一个打开的缓冲区被丢弃（使用 `^O^Q` 或 `^X^Q`）时，退出状态为 `2`。

## 帮助查看器

按 `^G` 可以使用 `nano` 的内置帮助。它相当易懂。它记录了编辑器的各个部分以及可用的按键。导航通过 `^Y`（Page Up）和 `^V`（Page Down）键进行。`^X` 退出帮助查看器。

---

## 文件浏览器

在读取文件（`^R`）或写出菜单（`^O`）中，按 `^T` 会调用文件浏览器。在这里，你可以以图形方式浏览目录，以找到所需的文件。

文件浏览器中的基本移动通过箭头键和其他光标移动键完成。更有针对性的移动通过搜索（`^W` 或 `w`）或更改目录（`^_` 或 `g`）来完成。`Enter` 键（或 `s`）的行为因当前选中的对象而异。如果当前选中的对象是目录，文件浏览器会进入并显示该目录的内容。如果对象是文件，则此文件名和路径会复制到状态栏，并且文件浏览器退出。

## 命令行选项

`nano` 接受以下命令行选项：

| 选项 | 描述 |
|--------|-------------|
| `-A`、`--smarthome` | 让 Home 键更智能。当在一行的非空白字符开头以外的任何位置按下 Home 时，光标会跳转到该开头（向前或向后）。如果光标已经在该位置，它会跳转到行的真正开头。 |
| `-B`、`--backup` | 保存文件时，备份其先前版本，使用当前文件名并附加波浪号（`~`）作为后缀。 |
| `-C directory`、`--backupdir=directory` | 不仅创建一个备份文件，而且在每次保存文件时（当启用备份时）创建并保留一个唯一编号的备份文件。这些唯一编号的文件存储在指定目录中。 |
| `-D`、`--boldtext` | 对于界面，使用粗体而不是反显。可以通过在 nanorc 文件中设置 `titlecolor`、`statuscolor`、`promptcolor`、`minicolor`、`keycolor`、`numbercolor` 和/或 `selectedcolor` 选项来为特定元素覆盖此设置。有关详细信息，请参见 [set keycolor](#set-keycolor)。 |
| `-E`、`--tabstospaces` | 将每个键入的制表符转换为空格——转换为该位置上制表符所占用的空格数。（注意：粘贴的制表符不会被转换。） |
| `-F`、`--newbuffer` | 默认将文件读入新缓冲区。（此选项的旧形式 `--multibuffer` 已弃用。） |
| `-G`、`--locking` | 编辑文件时启用 vim 风格的文件锁定。 |
| `-H`、`--historylog` | 保存最近一百个搜索字符串、替换字符串和执行过的命令，以便在以后的会话中轻松重用。 |
| `-I`、`--ignorercfiles` | 不查看系统的 nanorc 文件，也不查看用户的 nanorc 文件。 |
| `-J`、`--guidestripe` | 在给定列处绘制一条垂直条纹，以帮助判断文本的宽度。（条纹的颜色可以通过 nanorc 文件中的 `set stripecolor` 更改。） |
| `-K`、`--rawsequences` | 直接解释转义序列，而不是要求 `ncurses` 转换它们。（如果你需要此选项才能使某些按键正常工作，则意味着所使用的 terminfo 终端描述与你的终端实际行为不完全匹配。例如，当你通过 ssh 连接到 BSD 机器时可能会发生这种情况。）使用此选项会禁用 `nano` 的鼠标支持。 |
| `-L`、`--nonewlines` | 当文本不以换行符结尾时，不自动添加换行符。（这可能导致你保存非 POSIX 文本文件。） |
| `-M`、`--trimblanks` | 当发生自动硬换行或文本被调整时，从换行行中剪掉尾随空白。 |
| `-N`、`--noconvert` | 禁用从 DOS 格式自动转换文件。 |
| `-O`、`--bookstyle` | 调整时，将以空白开头的任何行视为段落的开头（除非启用了自动缩进）。 |
| `-P`、`--positionlog` | 对于最近 200 个文件，记录光标的最后位置，并在重新打开此类文件时将其放回该位置。同时保存和恢复任何锚点的位置。 |
| `-Q "regex"`、`--quotestr="regex"` | 设置用于匹配行中引用部分的正则表达式。默认值为 `"^([[:space:]\t]*([!#%:;[>|]|//))]+"`。（注意 `\t` 代表字面 Tab 字符。）这使得在撰写电子邮件时可以重新调整引用文本块，在编写源代码时可以重新换行行注释块。 |
| `-R`、`--restricted` | 仅读取和写入命令行上指定的文件（或多个文件）。这意味着：不读取或写入历史文件；不允许挂起；不允许拼写检查；不允许在 shell 中执行任何命令；不允许将当前缓冲区以不同名称保存；不允许向任何文件追加或前置内容；不创建备份文件。作为例外，在指定文件之前，会读取 nanorc 文件，以允许自定义。如果不允许自定义，请同时使用选项 `-I`（`--ignorercfiles`）。当命令行上未指定文件时，受限模式允许你以任何名称保存输入到新缓冲区中的内容，但不得覆盖现有文件。如果应限制此新文件可能创建的位置，则同时使用选项 `-o`（`--operatingdir`）。受限模式也可以通过以 `r` 开头的名称调用 `nano` 来激活（例如：`rnano`）。 |
| `-S`、`--softwrap` | 在多个屏幕行上显示超过屏幕宽度的行。（通过同时使用 `--atblanks`，可以使这种软换行在空白处发生，而不是生硬地在屏幕边缘发生。） |
| `-T number`、`--tabsize=number` | 将显示的制表符长度设置为 `number` 列。`number` 的值必须大于 0。默认值为 `8`。 |
| `-U`、`--quickblank` | 使状态栏消息在 1 次按键后消失，而不是 20 次后。注意，选项 `-c`（`--constantshow`）会覆盖此选项。当选项 `--minibar` 或 `--zero` 生效时，`--quickblank` 会使消息在 0.8 秒后消失，而不是默认的 1.5 秒。 |
| `-V`、`--version` | 显示当前版本号并退出。 |
| `-W`、`--wordbounds` | 通过将标点字符视为单词的一部分，以不同的方式检测单词边界。 |
| `-X "characters"`、`--wordchars="characters"` | 指定除了普通字母数字字符之外，哪些其他字符应被视为单词的一部分。使用此选项时，你可能希望省略 `-W`（`--wordbounds`）。 |
| `-Y name`、`--syntax=name` | 指定用于高亮的语法。有关更多信息，请参见 [语法高亮](#syntax-highlighting)。 |
| `-Z`、`--zap` | 让未修改的 `Backspace` 或 `Delete` 擦除标记区域（而不是单个字符，并且不影响剪切缓冲区）。 |
| `-a`、`--atblanks` | 进行软换行时，在空白处换行，而不是始终在屏幕边缘换行。 |
| `-b`、`--breaklonglines` | 当当前行变得超长时自动硬换行，即：当行宽超过 `-r`（`--fill`）给定的值时。`-r` 的默认值是终端宽度减去八。（此选项与 `-w`（`--nowrap`）相反——最后给出的选项生效。） |
| `-c`、`--constantshow` | 在状态栏上持续报告光标位置（行号、列号和字符号）。注意，这会覆盖选项 `-U`（`--quickblank`）。 |
| `-d`、`--rebinddelete` | 以不同方式解释 `Delete` 和 `Backspace` 键，以便两者都正常工作。你只应在系统上 `Backspace` 行为类似 Delete 或 `Delete` 行为类似 Backspace 时使用此选项。 |
| `-e`、`--emptyline` | 不使用标题栏下方的一行，使其完全空白。 |
| `-f file`、`--rcfile=file` | 仅读取此 `file` 来设置 nano 的选项，而不是同时读取系统范围和用户的 nanorc 文件。 |
| `-g`、`--showcursor` | 在文件浏览器中使光标可见（将其置于高亮项上），并在帮助查看器中显示光标。对盲文用户和视力不佳的人有用。 |
| `-h`、`--help` | 显示命令行选项摘要并退出。 |
| `-i`、`--autoindent` | 自动将新创建的行缩进到与上一行（如果上一行是段落开头，则与下一行）相同数量的制表符和/或空格。 |
| `-j`、`--jumpyscrolling` | 按半屏滚动缓冲区内容，而不是按行滚动。 |
| `-k`、`--cutfromcursor` | 使“剪切文本”命令（通常为 `^K`）从当前光标位置剪切到行尾，而不是剪切整行。 |
| `-l`、`--linenumbers` | 在文本区域左侧显示行号。（任何带有锚点的行还会在边距中获得一个标记。） |
| `-m`、`--mouse` | 如果系统可用，启用鼠标支持。启用后，鼠标单击可用于放置光标、设置标记（两次单击）和执行快捷键。鼠标在 X Window 系统中有效，并且在运行 gpm 的控制台上也有效。通过按住 Shift 键，仍然可以通过拖动选择文本。 |
| `-n`、`--noread` | 将命令行上给出的任何名称视为新文件。这允许 `nano` 写入命名管道：它从一个空白缓冲区开始，并在用户保存“文件”时写入管道。这样，`nano` 可以用作编辑器与例如 `gpg` 结合使用，而无需先将敏感数据写入磁盘。 |
| `-o directory`、`--operatingdir=directory` | 切换到给定 `directory`，并且仅允许在该目录及其子目录中读取和写入文件。 |
| `-p`、`--preserve` | 保留 `^S`（XOFF）和 `^Q`（XON）序列，以便可以停止和恢复发送到终端的数据。注意，选项 `-/`（`--modernbindings`）会覆盖此选项。 |
| `-q`、`--indicator` | 在编辑窗口右侧显示一个“滚动条”。它显示视口在缓冲区中的位置以及视口覆盖了多少缓冲区。 |
| `-r number`、`--fill=number` | 将对齐和自动硬换行的目标宽度设置为此 `number` 列。如果值为 0 或更小，则换行发生在屏幕宽度减去 `number` 列处，允许换行点随屏幕宽度变化（如果屏幕被调整大小）。默认值为 `-8`。 |
| `-s "program [argument ...]"`、`--speller="program [argument ...]"` | 使用给定程序进行拼写检查和纠正。默认情况下，`nano` 使用 `SPELL` 环境变量中指定的命令。如果未设置 `SPELL`，且也未指定 `--speller`，则 `nano` 使用其自己的交互式拼写纠正器，这需要安装 `hunspell` 或 GNU `spell`。 |
| `-t`、`--saveonexit` | 在退出时（使用 `^X`）保存已更改的缓冲区而不提示。当 `nano` 用作电子邮件程序的编辑器时，这很方便。 |
| `-u`、`--unix` | 默认以 Unix 格式保存文件。这覆盖了 nano 默认以文件原有格式保存的行为。（当你同时使用 `--noconvert` 时，此选项无效。） |
| `-v`、`--view` | 不允许更改文件内容：只读模式。此模式还允许用户打开其他文件进行查看，除非同时给出了 `--restricted`。（注意，此选项不应用于替代正确的文件权限来实现只读文件。） |
| `-w`、`--nowrap` | 当当前行变得超长时，不自动硬换行。这是默认设置。（此选项与 `-b`（`--breaklonglines`）相反——最后给出的选项生效。） |
| `-x`、`--nohelp` | 专家模式：不显示屏幕底部的两行帮助行。这也会影响状态栏的位置，因为在专家模式下，状态栏位于编辑器的最底部。注意：访问帮助系统时，专家模式会暂时禁用，以显示帮助系统的导航键。 |
| `-y`、`--afterends` | 使 `Ctrl+Right` 和 `Ctrl+Delete` 在单词结尾处停止，而不是在开头处停止。 |
| `-z`、`--listsyntaxes` | 列出可用语法的名称并退出。 |
| `-!`、`--magic` | 当文件的名称和第一行都无法提供线索时，尝试使用 libmagic 确定适用的语法。 |
| `-@`、`--colonparsing` | 当命令行上给出的文件名以冒号加数字结尾且此文件不存在时，则去掉冒号加数字，并将数字理解为行号。如果去掉后的文件名也不存在，则重复此过程，并将获得的两个数字理解为行号和列号。但如果二次去掉后的文件名也不存在，则放弃去掉，按原样接受原始文件名。要为某些文件禁用此冒号解析，请在相关文件名前使用 `+1` 或类似内容。 |
| `-%`、`--stateflags` | 使用屏幕右上角显示一些状态标志：自动缩进时显示 `I`，标记打开时显示 `M`，硬换行（断行）时显示 `L`，录制宏时显示 `R`，软换行时显示 `S`。当缓冲区被修改时，标题栏中间的文件名后会显示星号（`*`）。 |
| `-_`、`--minibar` | 抑制标题栏，改为在屏幕底部状态栏的位置显示有关当前缓冲区的信息。在此“迷你栏”中，文件名显示在左侧，如果缓冲区已被修改，则后跟一个星号。右侧显示当前行号和列号、光标下字符的代码（Unicode 格式：U+xxxx）、与 `--stateflags` 显示的相同标志，以及表示光标在文件中的位置（按行）的百分比。当文件被加载或保存时，以及切换缓冲区时，缓冲区中的行数会显示在文件名之后。此数字在下一次按键时清除，或者在打开多个缓冲区时替换为 [i/n] 计数器。行号加列号和字符代码仅在使用 `--constantshow` 时显示，并且可以使用 `M-C` 打开和关闭。状态标志仅在使用 `--stateflags` 时显示。 |
| `-0`、`--zero` | 隐藏界面的所有元素（标题栏、状态栏和帮助行），并使用终端的所有行来显示缓冲区内容。状态栏仅在有重要消息时出现，并在 1.5 秒后或下一次按键时消失。使用 `M-Z` 可以切换标题栏加状态栏。使用 `M-X` 可以切换帮助行。 |
| `-1`、`--solosidescroll` | 当光标接近编辑窗口的右边缘时，仅将当前行横向滚动较大步长，而不是将所有可见行横向滚动仅保持光标可见所需的量。后一种整个窗口的平滑横向滚动是新的默认行为。此选项启用的单行跳跃式横向滚动是旧行为——`nano` 以前唯一知道的行为。 |
| `-/`、`--modernbindings` | 使用与大多数现代程序相似的键绑定：`^X` 剪切，`^C` 复制，`^V` 粘贴，`^Z` 撤销，`^Y` 重做，`^F` 正向搜索，`^G` 搜索下一个，`^S` 保存，`^O` 打开文件，`^Q` 退出，并且（当终端允许时）`^H` 显示帮助。此外，`^A` 设置标记，`^B` 反向搜索，`^D` 搜索上一个，`^R` 进行替换，`^P` 显示位置，`^T` 转到行，`^W` 写出文件，`^E` 执行命令。注意，此选项覆盖选项 `-p`（`--preserve`）。 |

默认启用挂起，可通过 `^T^Z` 到达。（如果你希望使用普通 `^Z` 挂起 nano，请将 `bind ^Z suspend main` 添加到你的 nanorc 中。）

## 功能开关

开关允许你在编辑时更改编辑器的某些方面，这些方面通常通过命令行选项或 nanorc 选项指定。每个开关都可以通过 Meta 键组合来切换——`Meta` 键通常是 `Alt` 键（有关更多详细信息，请参见 [命令](#commands)）。以下全局开关可用：

| 开关 | 描述 |
|--------|-------------|
| 持续光标位置显示 | `M-C` 切换 `-c`（`--constantshow`）命令行选项。 |
| 智能 Home 键 | `M-H` 切换 `-A`（`--smarthome`）命令行选项。 |
| 自动缩进 | `M-I` 切换 `-i`（`--autoindent`）命令行选项。 |
| 从光标剪切到行尾 | `M-K` 切换 `-k`（`--cutfromcursor`）命令行选项。 |
| 长行换行 | `M-L` 切换 `-b`（`--breaklonglines`）命令行选项。 |
| 鼠标支持 | `M-M` 切换 `-m`（`--mouse`）命令行选项。 |
| 行号 | `M-N` 切换 `-l`（`--linenumbers`）命令行选项。 |
| 制表符转空格 | `M-O` 切换 `-E`（`--tabstospaces`）命令行选项。 |
| 空白显示 | `M-P` 切换空白显示（参见 [空白](#whitespace)）。 |
| 软换行 | `M-S` 切换 `-S`（`--softwrap`）命令行选项。 |
| 专家模式 | `M-X` 切换 `-x`（`--nohelp`）命令行选项。 |
| 语法着色 | `M-Y` 切换语法着色，当你的 nanorc 定义了语法时（参见 [语法高亮](#syntax-highlighting)）。 |
| 隐藏界面 | `M-Z` 切换 `-0`（`--zero`）命令行选项，但不包括 `-x`（`--nohelp`）部分。即：它只切换标题栏加状态栏（或组合的迷你栏加状态栏），而不是帮助行。后者用 `M-X` 切换。 |

## Nanorc 文件

Nanorc 文件可用于根据你的喜好配置 `nano`，而无需使用命令行选项。在启动期间，`nano` 通常会读取两个文件：首先是系统范围的 `/etc/nanorc`（在你的系统上确切路径可能不同），然后是用户特定的文件，即 `~/.nanorc` 或 `$XDG_CONFIG_HOME/nano/nanorc` 或 `.config/nano/nanorc`，以先存在者为准。但是，如果给出了 `--rcfile`，`nano` 会跳过上述文件，只读取指定的设置文件。

Nanorc 文件可以包含各种选项的 `set` 和 `unset` 命令（参见 [设置](#settings)）。它还可以包含定义语法高亮的命令（参见 [语法高亮](#syntax-highlighting)）和重新绑定按键的命令（参见 [重新绑定按键](#rebinding-keys)）。每个命令应位于单独的行上，并且所有命令都应使用小写字母。

不带参数的选项默认未设置。因此，仅当你想在自己的 nanorc 中覆盖系统 nanorc 文件的设置时，才需要使用 `unset` 命令。带参数的选项无法取消设置，但可以赋值为空字符串。

当然，任何命令行选项都会覆盖其 nanorc 设置。

以下 `characters` 参数内的引号不应转义。行上的最后一个双引号将被视为结束引号。

### 设置

nanorc 文件中支持的设置如下：

| 设置 | 描述 |
|---------|-------------|
| `set afterends` | 使 `Ctrl+Right` 和 `Ctrl+Delete` 在单词结尾处停止，而不是在开头处停止。 |

| `set backupdir "directory"` | 不仅创建一个备份文件，而且在每次保存文件时（当使用 `set backup` 或 `--backup` 或 `-B` 启用备份时）创建并保留一个唯一编号的备份文件。这些唯一编号的文件存储在指定目录中。 |

| `set colonparsing` | 当命令行上给出的文件名以冒号加数字结尾且此文件不存在时，则去掉冒号加数字，并将数字理解为行号。如果去掉后的文件名也不存在，则重复此过程，并将获得的两个数字理解为行号和列号。但如果二次去掉后的文件名也不存在，则放弃去掉，按原样接受原始文件名。要为某些文件禁用此冒号解析，请在相关文件名前使用 `+1` 或类似内容。 |
| `set constantshow` | 在状态栏上持续报告光标位置。注意，这会覆盖 `quickblank`。 |
| `set cutfromcursor` | 默认使用从光标剪切到行尾，而不是剪切整行。 |
| `set emptyline` | 不使用标题栏下方的一行，使其完全空白。 |
| `set errorcolor [bold,][italic,]fgcolor,bgcolor` | 当显示错误消息时，对状态栏使用此颜色组合。默认值为 `bold,white,red`。有关有效颜色名称，请参见 [set keycolor](#set-keycolor)。 |

| `set functioncolor [bold,][italic,]fgcolor,bgcolor` | 对屏幕底部两行帮助行中的简洁功能描述使用此颜色组合。有关有效颜色名称，请参见 [set keycolor](#set-keycolor)。 |
| `set guidestripe number` | 在给定列处绘制一条垂直条纹，以帮助判断文本的宽度。（条纹的颜色可以通过 `set stripecolor` 更改。） |
| `set historylog` | 保存最近一百个搜索字符串、替换字符串和执行过的命令，以便在以后的会话中轻松重用。 |
| `set indicator` | 在编辑窗口右侧显示一个“滚动条”。它显示视口在缓冲区中的位置以及视口覆盖了多少缓冲区。 |
| `set jumpyscrolling` | 按半屏滚动缓冲区内容，而不是按行滚动。 |
| <a name="set-keycolor">`set keycolor [bold,][italic,]fgcolor,bgcolor`</a> | 对屏幕底部两行帮助行中的快捷键组合使用此颜色组合。有效的前景色和背景色名称有：`red`、`green`、`blue`、`magenta`、`yellow`、`cyan`、`white` 和 `black`。这八个名称中的每一个都可以加上前缀 `light` 以获得更亮的版本。单词 `grey` 或 `gray` 可以用作 `lightblack` 的同义词。在 Linux 控制台上，`light` 对背景色没有任何影响。在能够显示至少 256 种颜色的终端模拟器上，其他有效（但不可加前缀）的颜色名称有：`pink`、`purple`、`mauve`、`lagoon`、`mint`、`lime`、`peach`、`orange`、`latte`、`rosy`、`beet`、`plum`、`sea`、`sky`、`slate`、`teal`、`sage`、`brown`、`ocher`、`sand`、`tawny`、`brick`、`crimson` 和 `normal`——其中 `normal` 表示默认前景色或背景色。在此类模拟器上，颜色也可以指定为以 `#` 为前缀的三位十六进制数，这些数字分别表示红色、绿色和蓝色的量。这告诉 `nano` 从可用调色板中选择最接近给定值的颜色。可以省略 `fgcolor` 或 `,bgcolor`，并且该对可以以 `bold` 和/或 `italic`（用逗号分隔）开头，以获得粗体和/或斜体字体（如果你的终端能够做到）。 |

| `set locking` | 编辑文件时使用 vim 风格的锁文件。 |
| `set magic` | 当文件的名称和第一行都无法提供线索时，尝试使用 libmagic 确定适用的语法。（调用 libmagic 可能相对耗时。因此默认不执行。） |
| <a name="set-matchbrackets">`set matchbrackets "characters"`</a> | 指定括号搜索可以找到的开括号和闭括号。这不能包含空白字符。开括号集必须位于闭括号集之前，并且两个集合必须按相同顺序排列。默认值为 `([<{}>])]`。 |

| `set minicolor [bold,][italic,]fgcolor,bgcolor` | 对迷你栏使用此颜色组合。（如果未指定此选项，则使用标题栏的颜色。）有关有效颜色名称，请参见 [set keycolor](#set-keycolor)。 |
| `set mouse` | 启用鼠标支持，以便鼠标单击可用于放置光标、设置标记（两次单击）或执行快捷键。 |
| `set newbuffer` | 使用 `^R` 读入文件时，默认将其插入新缓冲区。（此选项的旧形式 `set multibuffer` 已弃用。） |
| `set noconvert` | 不从 DOS 格式转换文件。 |
| `set nohelp` | 不显示屏幕底部的帮助列表。 |
| `set nonewlines` | 当文本不以换行符结尾时，不自动添加换行符。（这可能导致你保存非 POSIX 文本文件。） |
| `set nowrap` | 已弃用的选项，因为它已成为默认设置。需要时，请改用 `unset breaklonglines`。 |
| `set numbercolor [bold,][italic,]fgcolor,bgcolor` | 对行号使用此颜色组合。有关有效颜色名称，请参见 [set keycolor](#set-keycolor)。 |

| `set preserve` | 保留 XOFF 和 XON 序列（`^S` 和 `^Q`），以便终端捕获它们（停止和恢复输出）。 |
| `set promptcolor [bold,][italic,]fgcolor,bgcolor` | 对提示栏使用此颜色组合。（如果未指定此选项，则使用标题栏的颜色。）有关有效颜色名称，请参见 [set keycolor](#set-keycolor)。 |

### 语法高亮

对文件的不同语法元素进行着色是通过正则表达式完成的（参见下面的 `color` 命令）。这本质上是不完美的，因为正则表达式不足以完全解析文件。尽管如此，正则表达式能做很多事情，而且很容易编写，因此它们非常适合像 `nano` 这样的小型编辑器。

有关开箱即用的语法着色定义，请参见 `/usr/share/nano/` 和 `/usr/share/nano/extra/`。

`nano` 中的所有正则表达式都是 POSIX 扩展正则表达式（ERE）。这意味着 `.`、`?`、`*`、`+`、`^`、`$` 和其他几个字符是特殊的。句点 `.` 匹配任意单个字符，`?` 表示前一项是可选的，`*` 表示前一项可以匹配零次或多次，`+` 表示前一项必须匹配一次或多次，`^` 匹配行的开头，`$` 匹配行的结尾，`\<` 匹配单词的开头，`\>` 匹配单词的结尾，`\s` 匹配空白。这也意味着不可能进行前瞻和后顾。完整的解释可以在 GNU grep 的手册中找到：`info grep regular`。

`nanorc` 文件中的每个正则表达式都应使用双引号（`""`）括起来。多个正则表达式可以通过用空白分隔而在同一行上相互跟随。这意味着正则表达式不能包含后跟空白的双引号。当你在正则表达式中需要这种组合时，应将双引号或空白放在方括号（`[]`）内。

可以通过 nanorc 文件中的以下命令为每种文件定义单独的语法：

| 命令 | 描述 |
|---------|-------------|
| `syntax name ["fileregex" ...]` | 使用此 `name` 开始定义一个语法。所有后续的 `color` 和其他此类命令都会添加到此语法中，直到遇到新的 `syntax` 命令。当 `nano` 运行时，如果绝对文件名匹配扩展正则表达式 `fileregex`，则此语法会自动激活（针对相关缓冲区）。或者，可以通过使用 `-Y` 或 `--syntax` 命令行选项后跟 `name` 来显式激活语法（针对所有缓冲区）。`default` 语法是特殊的：它不接受 `fileregex`，并且适用于不匹配任何语法正则表达式的文件。`none` 语法是保留的；在命令行上指定它与完全没有语法相同。 |
| `header "regex" ...` | 如果所有已定义语法的 `fileregex` 均未匹配，则将此 `regex`（或多个正则表达式）与当前文件的第一行进行比较，以确定是否应使用此语法。 |
| `magic "regex" ...` | 如果既没有 `fileregex` 匹配，也没有 `header` 正则表达式匹配，则将此 `regex`（或多个正则表达式）与查询 `magic` 数据库关于当前文件的结果进行比较，以确定是否应使用此语法。（仅当系统上实际安装了 `libmagic` 并且给出了 `--magic` 或 `set magic` 时，才会执行此查询。） |
| `formatter program [argument ...]` | 对当前缓冲区的全部内容运行给定 `program`。 |
| `linter program [argument ...]` | 使用给定 `program` 对当前缓冲区执行语法检查。 |
| `comment "string"` | 使用给定字符串进行注释和取消注释行。如果字符串包含竖线或管道字符（`\|`），则这表示括号式注释；例如，CSS 文件的 `"/*\|*/"`。管道符之前的字符会被添加到行首，管道符之后的字符会被附加到行尾。如果不存在管道符，则完整字符串会被添加到行首；例如，Python 文件的 `"#"`。如果双引号之间未指定任何内容，则注释/取消注释功能会被禁用；例如，JSON 的 `""`。默认值为 `"#"`。 |
| `tabgives "string"` | 使 <Tab> 键产生给定 `string`。对于像 Python 这样希望仅使用空格进行缩进的语言很有用。这会覆盖 `tabstospaces` 选项的设置。 |
| `color [bold,][italic,]fgcolor,bgcolor "regex" ...` | 使用给定的前景色和背景色（至少必须指定其中一个）为所有匹配扩展正则表达式 "regex" 的文本片段着色。有效颜色名称为：`red`、`green`、`blue`、`magenta`、`yellow`、`cyan`、`white` 和 `black`。这八个名称中的每一个都可以加上前缀 `light` 以获得更亮的版本。单词 `grey` 或 `gray` 可以用作 `lightblack` 的同义词。在 Linux 控制台上，`light` 对背景色没有任何影响。在能够显示至少 256 种颜色的终端模拟器上，其他有效（但不可加前缀）的颜色名称有：`pink`、`purple`、`mauve`、`lagoon`、`mint`、`lime`、`peach`、`orange`、`latte`、`rosy`、`beet`、`plum`、`sea`、`sky`、`slate`、`teal`、`sage`、`brown`、`ocher`、`sand`、`tawny`、`brick`、`crimson` 和 `normal`——其中 `normal` 表示默认前景色或背景色。在此类模拟器上，颜色也可以指定为以 `#` 为前缀的三位十六进制数，这些数字分别表示红色、绿色和蓝色的量。这告诉 `nano` 从可用调色板中选择最接近给定值的颜色。颜色对可以以 `bold` 和/或 `italic`（用逗号分隔）开头，以获得粗体和/或斜体字体（如果你的终端能够做到）。所有着色命令都按指定的顺序应用，这意味着后面的命令可以重新着色前面已着色的内容。 |
| `icolor [bold,][italic,]fgcolor,bgcolor "regex" ...` | 与上面相同，只是匹配不区分大小写。 |
| `color [bold,][italic,]fgcolor,bgcolor start="fromrx" end="torx"` | 使用给定的前景色和背景色（至少必须指定其中一个）为所有开始匹配扩展正则表达式 `fromrx` 且结束匹配扩展正则表达式 `torx` 的文本片段着色。这意味着，在初始的 `fromrx` 实例之后，直到第一个 `torx` 实例的所有文本都被着色。这允许语法高亮跨越多行。 |
| `icolor [bold,][italic,]fgcolor,bgcolor start="fromrx" end="torx"` | 与上面相同，只是匹配不区分大小写。 |
| `include "syntaxfile"` | 从 `syntaxfile` 读入独立的颜色语法。注意，此类语法文件可能只包含上述命令，从 `syntax` 到 `icolor`。 |
| `extendsyntax name command argument ...` | 使用另一个 `command` 扩展先前定义为“`name`”的语法。这允许你向已经定义的语法添加新的 `color`、`icolor`、`header`、`magic`、`formatter`、`linter`、`comment` 或 `tabgives` 命令——当你想要稍微改进系统安装文件（通常不可写）中定义的语法时很有用。 |

### 重新绑定按键

可以通过 nanorc 文件中的以下三个命令更改按键绑定：

| 命令 | 描述 |
|---------|-------------|
| `bind key function menu` | 在 `menu` 的上下文中将 `key` 重新绑定到 `function`（或当使用 `all` 时，在所有存在该功能的菜单中）。 |
| `bind key "string" menu` | 在 `menu` 的上下文中使 `key` 产生 `string`（或当使用 `all` 时，在所有存在该键的菜单中）。除了字面文本和/或控制代码之外，`string` 还可以包含大括号之间的函数名称。当键入该键时，会调用这些函数。要包含字面左大括号，请使用 `{{{`。 |
| `unbind key menu` | 从 `menu` 中解除绑定 `key`（或当使用 `all` 时，从所有存在该键的菜单中解除绑定）。 |

注意，`bind key "{function}" menu` 等同于 `bind key function menu`，区别在于，对于后一种形式，`nano` 在启动时检查给定 `menu` 中 `function` 的可用性（如果不存在则报告错误），而对于第一种形式，`nano` 在执行时检查 `function` 是否存在，但不检查它在当前菜单中是否有意义。用户必须注意大括号之间的函数名（或它们的任何序列）是否合适。当大括号中的名称不合适时，可能会导致奇怪的行为甚至崩溃。

`key` 的格式应为以下之一：

- `^X`，其中 `X` 是拉丁字母，或几个 ASCII 字符之一（@、]、\、^、_），或单词 "Space"。示例：`^C`。
- `M-X`，其中 `X` 是除 [ 之外的任何 ASCII 字符，或单词 "Space"、"Left"、"Right"、"Up"、"Down"、"Ins" 或 "Del"。示例：`M-8`。
- `Sh-M-X`，其中 `X` 是拉丁字母。示例：`Sh-M-U`。默认情况下，每个 Shift+Meta+字母按键都执行与相应 Meta+字母相同的操作。但是，一旦进行了任何 Shift+Meta 绑定，对于所有字母，情况将不再如此。
- `Fn`，其中 `n` 是从 1 到 24 的数值。示例：`F10`。（通常，`F13` 到 `F24` 可以通过 Shift 加 `F1` 到 `F12` 输入。）
- `Ins` 或 `Del`

重新绑定 `^M`（Enter）或 `^I`（Tab）可能不是一个好主意。重新绑定 `^[`（Esc）是不可能的，因为它的键码是 Meta 按键和转义序列的起始字节。重新绑定任何专用的光标移动键（Home、End、PageUp、PageDown 和箭头键）是不可能的。在某些终端上，无法重新绑定 `^H`（除非使用 `--raw`），因为它的键码与 Backspace 键的键码相同。

## Pico 兼容性

`nano` 非常接近地模拟 Pico，但两个编辑器之间存在一些差异：

| 特性 | 差异 |
|---------|------------|
| 硬换行 | 与 Pico 不同，`nano` 在键入过程中当前行变得超长时不会自动硬换行。可以通过 `--breaklonglines` 选项打开此硬换行。使用该选项时，`nano` 默认在屏幕宽度减八列处断行，而 Pico 在屏幕宽度减六列处断行。你可以通过使用 `--fill=-6` 使 `nano` 的行为与 Pico 相同。 |
| 滚动 | 默认情况下，当光标移动到刚好在视图之外的行时，`nano` 仅滚动一行（而不是半屏）。并且当向上或向下翻页时，`nano` 尽可能将光标保持在相同的屏幕位置，而不是始终将其放在视口的第一行。可以通过 `--jumpyscrolling` 选项获得类似 Pico 的行为。 |
| 编辑区域 | Pico 从不使用标题栏正下方的行，使其始终空白。`nano` 将此行包含在编辑区域中，以便不浪费空间，并且因为这样可以稍微更清楚文本从哪里开始。如果你习惯此行空白，可以使用 `--emptyline` 选项恢复它。 |
| 交互式替换 | `nano` 的替换功能不是允许你仅替换搜索字符串的一次出现或全部出现，而是交互式的：它会在每个找到的搜索字符串处暂停，并询问是否替换此实例。然后你可以选择 Yes、No（跳过此一次）、All（不再询问）或 Cancel（停止替换）。 |
| 搜索和替换历史 | 当给出 `-H` 或 `--historylog` 选项（或在 nanorc 文件中设置）时，作为搜索或替换字符串输入的文本会被存储。这些字符串可以在各自的提示符处使用上/下箭头键访问，或者你可以输入前几个字符，然后使用 `Tab` 循环浏览匹配的字符串。检索到的字符串随后可以进行编辑。 |
| 位置历史 | 当给出 `-P` 或 `--positionlog` 选项（或在 nanorc 文件中设置）时，`nano` 会在你关闭文件时存储光标的位置，并在你以后重新打开文件时将光标置于该位置。 |
| 当前光标位置 | “显示光标位置”命令（`^C`）的输出不仅显示光标的当前行和字符位置，还在两者之间显示当前列位置。 |
| 拼写检查 | 在内部拼写检查器中，拼错的单词按字母顺序排序并去重，因此字符串 'Aplpe' 和 'aplpe' 将分别提供更正。 |
| 将选中文本写入文件 | 使用写出键（`^O`）时，使用标记键（`^^`）选中的文本不仅可以写出到新（或现有）文件，还可以追加或前置到现有文件。 |
| 从命令读取文本 | 使用读取文件键（`^R`）时，`nano` 不仅可以读取文件，还可以读取要运行的命令的输出（`^X`）。 |
| 从工作目录读取 | 默认情况下，Pico 从用户主目录读取文件（使用 `^R` 时），但将文件写入当前工作目录（使用 `^O` 时）。`nano` 使这一点对称：始终从当前工作目录读取和写入——即 `nano` 启动时所在的目录。 |
| 文件浏览器 | 在文件浏览器中，`nano` 不实现 Pico 提供的 Add、Copy、Rename 和 Delete 命令。在 `nano` 中，浏览器只是文件浏览器，不是文件管理器。 |
| 开关 | 许多改变程序功能的选项可以使用 Meta 键序列“切换”开或关，这意味着不必重新启动程序即可打开或关闭特定功能。有关可以切换的选项列表，请参见 [功能开关](#feature-toggles)。或者参见主内部帮助文本（`^G`）末尾的列表。 |

## 构建及其选项

如果你熟悉使用 autoconf 支持编译程序，那么从源代码构建 `nano` 是简单的：

```bash
tar -xf nano-x.y.tar.gz
cd nano-x.y
./configure
make
make install
```

`./configure` 的可能选项如下：

| 选项 | 描述 |
|--------|-------------|
| `--disable-browser` | 排除可通过 `^T` 调用的文件浏览器（当想要读取或写入文件时）。 |
| `--disable-color` | 排除对语法着色的支持。这也会消除 `-Y` 命令行选项，该选项允许选择特定语法。 |
| `--disable-comment` | 排除单键注释/取消注释功能（`M-3`）。 |
| `--disable-extra` | 排除复活节彩蛋：对主要贡献者的爬取。 |
| `--disable-formatter` | 排除调用格式化工具的代码。 |
| `--disable-help` | 排除帮助文本（`^G`）。这使二进制文件小得多，但也使新用户难以学习使用编辑器的非常基本的东西。 |
| `--disable-histories` | 排除处理历史文件的代码：使用过的搜索和替换字符串、执行过的命令以及每个文件关闭时的光标位置。这也会消除 `-H` 和 `-P` 命令行选项，它们打开搜索/替换字符串、执行过的命令和光标位置的存储。 |
| `--disable-justify` | 排除文本调整功能（`^J` 和 `M-J`）。 |
| `--disable-libmagic` | 排除使用魔数测试库的代码（用于确定文件类型，从而确定用于着色的语法——在大多数情况下，文件名和标题行的正则表达式就足够了）。 |
| `--disable-linenumbers` | 排除显示行号的能力。这也会消除 `-l` 命令行选项，该选项打开行编号。 |
| `--disable-linter` | 排除调用 linting 工具的代码。 |
| `--disable-mouse` | 排除所有鼠标功能。这也会消除 `-m` 命令行选项，该选项启用鼠标功能。 |
| `--disable-multibuffer` | 排除一次打开多个文件并在它们之间切换的支持。这也会消除 `-F` 命令行选项，该选项导致文件默认读入单独的缓冲区。 |
| `--disable-nanorc` | 排除在启动时读取 nanorc 文件的支持。有了这种支持，你可以将自定义设置存储在系统范围和每个用户的 nanorc 文件中，而不是必须传递命令行选项来获得所需的行为。有关更多信息，请参见 [Nanorc 文件](#nanorc-files)。禁用此功能也会消除 `-I` 命令行选项，该选项禁止读取 nanorc 文件。 |
| `--disable-operatingdir` | 排除设置操作目录的代码。这也会消除 `-o` 命令行选项，该选项设置操作目录。 |
| `--disable-speller` | 排除拼写检查的代码。这也会消除 `-s` 命令行选项，该选项允许指定备用拼写检查器。 |
| `--disable-tabcomp` | 排除制表符补全（当 nano 询问文件名、搜索字符串、替换字符串或要执行的命令时）。 |
| `--disable-wordcomp` | 排除单词补全（`^]`）。 |
| `--disable-wrapping` | 排除所有超长行的硬换行。这也会消除 `-b` 和 `-w` 命令行选项，它们分别打开和关闭自动长行换行。 |
| `--enable-tiny` | 此选项隐含以上所有内容。它还禁用了编辑器的一些其他内部功能，如功能开关、文本标记、撤销/重做代码、行锚点、宏的录制和重放、软换行以及剪切到行尾代码。即使将上述选项的启用对应项与 `--enable-tiny` 一起使用以重新打开特定功能，这些功能也保持禁用状态。 |
| `--enable-debug` | 包含一些用于运行时调试输出的代码。这可能会变得混乱，所以很可能你只会在开发 nano 源代码时才需要此功能。 |
| `--disable-nls` | 排除本机语言支持。这会禁用任何可用的 GNU `nano` 翻译。 |
| `--enable-utf8` | 包含处理并显示 Unicode 文件的支持。这需要“宽”版本的 curses 库。 |
| `--disable-utf8` | 排除处理并显示 Unicode 文件的支持。通常，配置脚本会自动检测是否启用 UTF-8 支持。你可以使用此选项或前一个选项来覆盖该检测。 |
| `--enable-altrcname=name` | 使用用户主目录中具有给定 `name` 的文件作为 nano 的设置文件，而不是默认的 `.nanorc`。 |
